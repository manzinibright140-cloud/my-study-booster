YOUR EXAM CHEER — PERSONAL EDITION

Files:
- index.html: the page content
- style.css: colours, layout, mobile responsiveness, and animations
- script.js: encouragement buttons, checklist, and focus timer

How to use:
1. Extract the ZIP file into a folder.
2. Keep all three files together in the same folder.
3. Open index.html in a modern browser, or open the folder in Visual Studio Code and use Live Server.
4. The page can work without internet once opened, but the optional Google Fonts may need an internet connection.

Features:
- Responsive layout for phones and computers
- Random exam pep talks and kind reminders
- A study checklist that saves progress in the browser
- A 25-minute focus / 5-minute break timer
- Motion-reduction support for devices that request reduced animation

The checklist is stored locally in your browser and is not sent to a server.
